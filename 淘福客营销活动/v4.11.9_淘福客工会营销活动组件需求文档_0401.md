## 一、需求背景

基于部分客户对营销活动组件的真实需求，以及市场竞对功能调研下，设计开发如健步走、问卷答题等活动，丰富系统功能，帮助客户拓展市场、提高获客能力。

## 二、主要需求

1. 活动载体为淘福客营销活动小程序

2. 多种节假日活动模板

3. 活动类型主要为"健步走"和"答题"

4. 运营商可在系统后台进行活动创建、配置、统计信息查询

5. 支持对参与人员进行限制

## 四、功能页

### 4.1 登录首页

1. 顶部居中：圆角正方形logo，下方标题"淘福客工会营销活动"

2. 页面底部居中：

      1. “隐私政策”可点击跳转至隐私政策页

### 4.2 隐私政策页

1. 顶部标题“隐私政策”

2. 展示隐私政策，可滑动查看全文，右侧显示滚动条

3. 左上角返回按钮，点击可返回登录首页

### 4.3 活动列表

1. 顶部标题“活动列表”

2. 活动卡片：

   1. 包含活动主图、活动标题、活动时间、活动类型（健步走、问卷答题）、活动状态（进行中、已结束）

   2. 点击后跳转活动入口页

3. 筛选框：

   1. 活动状态：

      1. 点击后下拉框可选“全部”、“进行中”、“已结束”

      2. 默认展示全部

   2. 活动类型：

      1. 点击后下拉框可选“全部”、“健步走”、“问卷答题”

      2. 默认展示全部

4. 空白页面：

   1. 若无任何参与活动，显示文案"当前没有符合条件的活动"

5. 展示/排序规则

   1. 仅展示“进行中”和“已结束”的活动

   2. 进行中的活动排在已结束活动前面

   3. 同一活动状态，开始时间越晚越靠前。开始时间相同则结束时间越早越靠前

### 4.4 "我的"页面

1. 顶部标题“我的”

2. 列表主体纵向卡片式分布：

   1. 卡片1

      1. 文案“头像”、圆形头像缩略图、编辑引导箭头

         1. 点击编辑 → 下方弹窗，选项为“从手机相册选择” 

         2. 大小要≤5M，超出报错"请选取5M以内的图

         3. 符合大小的照片可以进入框选照片界面

         4. 左下角取消 → 点击返回“我的”页面

         5. 右下角保存 → 点击返回“我的”页面，更新头像。有保存成功提醒

      2. 文案“昵称”、昵称、编辑引导箭头

         1. 点击编辑 → 下方弹窗昵称编辑页

         2. 弹窗底部左边是取消，右边是保存

         3. 点击取消， → 点击返回“我的”页面

         4. 点击保存， → 点击返回“我的”页面，校验昵称长度≤20字符，仅支持中文/字母/下划线，不满时足保存失败，红字提醒“昵称长度≤20字符，仅支持中文/字母/下划线”

   2. 卡片2：

      1. 文案“隐私政策”、编辑引导箭头

         1. 点击后进入“隐私政策页”→左上角返回“我的”页面

   3. 卡片3（置于底部tab栏上方）：

      1. “退出登录”按钮

         1. 点击后弹窗提示，标题文案“退出提醒”

         2. 主体文案“确认要退出登录吗？”

         3. 左边按钮黑色字体“取消”，点击返回“我的”页面

         4. 右边按钮红色字体“退出登录”，点击返回登录首页

### 4.5 底部导航

#### 5.2.1 活动入口页

1. 顶部标题“活动入口”

2. 页面主体：

   1. 活动主图、活动标题、活动时间、活动介绍

3. 页面底部：

6. 活动未开始提醒弹窗

**交互说明**

```plain
用户扫码或从活动列表进入活动入口页，点击参与活动 
│
├─【途径 A：从“活动列表”点击进入】(已登录 且 已参与过该活动)
│   └─【活动状态校验】
│        ├─ 已结束 → 放行进入活动页 (只读查看）
│        └─ 进行中 → 放行进入活动页
│
└─【途径 B：扫描活动二维码进入】
    │
    ├─ 步骤一：【身份校验】(查询登录态)
    │   ├─ 未登录 → 弹出手机号授权窗
    │   │   ├─ 拒绝授权 → 停留在活动入口页
    │   │   └─ 同意授权 → 进入步骤二
    │   └─ 已登录 → 进入步骤二
    │
    ├─ 步骤二：【活动资格校验】（校验白名单）
    │   ├─ 开放活动 → 进入步骤三
    │   ├─ 封闭活动  
    │        ├─ 不在白名单 → 拦截提示"您无法参加当前活动" → 停留在活动入口页
    │        └─ 在名单 → 进入步骤三
    │
    ├─ 步骤三：【活动状态校验】
         ├─ 未开始 → 拦截提示"活动未开始" → 停留在活动入口页
         ├─ 已结束 → 拦截提示"活动已结束" → 停留在活动入口页
         └─ 进行中 → 放行进入主页
```


#### 5.2.2 健步走活动页

1. 顶部标题：活动名称

   1. 仅显示1行，超出页面部分省略号...代替

2. 获取微信运动步数权限

   1. 活动类型为健步走时，进入健步走首页先获取微信步数权限，不获取无法更新步数。

   2. 每次进入健步走页面都要查询是否有步数权限，没有就要请求获取

3. 页面主体：

   1. 圆形步数进度环

      1. 中间显示今日步数

      2. 今日步数下方为目标步数（运营商后台配置）

      3. 进度环按目标步数百分比填充颜色

   2. 步数更新按钮

      1. 点击 → 同步微信步数

      2. 每次进入页面都自动更新一次步数

      3. 若后台配置了每日更新步数上限，用户触发步数更新时，当日新增总步数达到上限后最多更新上限步数，多余步数不计，弹窗提醒“每日最多更新xxx步，请明日再来”

   3. 今日消耗热量

      1. 今日步数*0.04千卡

   4. 活动累计步数

      1. 从用户参与活动开始日期统计的总步数

      2. 右上角有点击引导箭头，点击后进入活动累计步数页

   5. 活动累计里程

      1. 活动累计步数*0.0007km

   6. 当前排名

      1. 当前用户在该活动全部参与用户中的排名

      2. 名次/总人数

4. 活动分享

   1. 点击 → 生成海报图片（包含活动主图、今日步数、累计步数、当前排名快照）

   2. 支持保存海报图片到本地，或分享给微信好友

   3. 可点击下方“叉号”按钮关闭分享弹窗

5. 活动详情

   1. 点击 → 进入活动详情页

6. 活动完成弹窗（本期是否做）

   1. 步数首次达到目标步数后，弹窗祝贺用户完成活动

   2. 标题文案“恭喜您完成活动！”展示累计步数（是否支持运营商自行配置，例如配置奖励文案）

   3. “去分享”按钮

      1. 点击 → 触发活动分享，生成活动分享海报（用活动主图，或者运营商自行上传，或者我方设计模板）

#### 5.2.3 活动详情页

1. 顶部标题：“活动详情”

2. 页面主体：

   1. 活动主图

   2. 运营商后台配置的活动信息（如：活动时间、活动介绍、活动规则、排行规则等）

3. 左上角返回按钮：

   1. 点击后返回原路由，例如：从入口页进入活动详情页，则返回入口页。从排行榜页面进入，则返回排行榜页

#### 5.2.4 活动累计步数页

1. 顶部标题：“活动累计步数”

2. 步数日历：

   1. 默认显示今日步数，并标记底色

   2. 点击<>可切换月份

   3. 点击年月可切换年月，但选择范围仅限活动日期

3. 左上角返回按钮

   1. 点击后返回健步走活动页

#### 5.2.5 排行榜页

1. 顶部标题：“排行榜”

2. 活动主图、“排行榜”文案

3. 排行榜：

   1. 展示名次+头像+昵称+步数

   2. 置顶突出展示个人成绩

   3. 1、2、3名底色标记名次

   4. 只展示每个用户的最好成绩

   5. 每当有人提交问卷时，触发一次排行榜更新

   6. 排序规则：

      1. 按活动累计步数降序

      2. 相同步数名次相同，视觉上先达成的用户排名靠前

## 六、运营商系统

### 6.1 活动管理

#### 6.1.1 活动列表

1. 页面顶部：

   1. 筛选区

      1. 活动编号：精准查询
