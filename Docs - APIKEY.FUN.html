Claude Code 配置教程

安装并配置 Claude Code CLI 工具，连接 APIKEY.FUN 平台。

Claude Code 是 Anthropic 官方 CLI 工具，强大的 AI 编程助手。本教程将引导你完成安装和配置。

⚠️ 注意：开始前请先完成 。

第一步：安装 Claude Code

Claude Code 支持多种安装方式，可按需选择。

需要 Node.js 18+ 环境:

BASH
npm install -g @anthropic-ai/claude-code

验证安装:

BASH
claude --version

2. 配置环境变量

配置以下环境变量，将 Claude Code 连接到 apikey.fun 中转服务。在个人中心获取你的 API 密钥。

ANTHROPIC_BASE_URLhttps://api.apikey.fun
ANTHROPIC_AUTH_TOKEN在个人中心获取
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC1
⚠️ 必须设置 CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1，此变量用于关闭 Claude Code 向 Anthropic 发送的非必要遥测流量。未设置可能导致设备信息泄露和账号异常。

临时设置（当前会话）

CMD
set ANTHROPIC_BASE_URL=https://api.apikey.fun
set ANTHROPIC_AUTH_TOKEN=your-key
set CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1
cd your-project
claude

永久设置

POWERSHELL
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.apikey.fun", [System.EnvironmentVariableTarget]::User)
[System.Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "your-key", [System.EnvironmentVariableTarget]::User)
[System.Environment]::SetEnvironmentVariable("CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC", "1", [System.EnvironmentVariableTarget]::User)
💡 提示：请将命令中的 your-key 替换为在 控制台 页面中复制的任意 API Key。

3. 开始使用

现在你可以开始使用 Claude Code 了！

BASH
claude

启动后，Claude Code 会分析当前目录的代码，并提供智能编程辅助。

更多使用说明请参考 Anthropic 官方文档 open_in_new。
