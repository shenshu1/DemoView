# 自有供应商系统优化 — 码上兑订单管理

## 一、需求背景

完善自有供应商管理系统功能，新增码上兑订单管理模块。

## 二、业务说明

```
码上兑订单生命周期
│
├── 用户购买 → 生成电子券码（有效期24小时）
│   ├── 24h内未核销 → 自动退款（供应商系统不同步该订单）
│   └── 24h内核销 → 订单同步至供应商系统
│       ├── 保持核销 → 订单状态：核销成功
│       └── 后续撤销 → 订单状态：已撤销
│
└── 注：供应商系统只展示核销过的订单
```

## 三、功能清单

| 序号 | 功能 | 说明 |
|:---:|------|------|
| 1 | 新增菜单 | 订单中心新增二级菜单"码上兑订单" |
| 2 | 订单列表 | 筛选 + 列表展示 |
| 3 | 查看订单详情 | 基本信息 + 码上兑信息 + 核销信息 |
| 4 | 导出订单 | 导出当前筛选结果 |
| 5 | 显示运营商名称 | 全局顶部栏展示供应商名称与运营商名称 |

### 4.2 查看订单详情

点击列表"查看详情"进入，包含三个模块：

#### 模块一：基本信息

| 字段 |
|------|
| 订单编号 |
| 下单时间 |

#### 模块二：码上兑信息

| 字段 | 说明 |
|------|------|
| 电子券码 | — |
| 券码状态 | 已核销 / 未核销 / 已作废 |
| 有效截止时间 | 下单时间 + 24小时 |
| 供应商结算金额（元） | — |

**券码状态判断逻辑：**

```
券码状态
│
├── 订单状态 = 核销成功
│   └── 券码状态：已核销
│
└── 订单状态 = 已撤销
    ├── 撤销时间 ≤ 有效截止时间 → 券码状态：未核销
    └── 撤销时间 > 有效截止时间 → 券码状态：已作废
```

#### 模块三：核销信息

| 字段 | 说明 |
|------|------|
| 核销门店 | — |
| 操作说明 | 已核销 / 已撤销 |
| 核销时间 | 所有订单都有值（核销后才同步） |
| 撤销时间 | 核销成功时为空，已撤销时有值 |
| 核销金额 | — |

**核销信息展示逻辑：**

```
核销信息
│
├── 订单状态 = 核销成功
│   ├── 操作说明：已核销
│   ├── 核销时间：有
│   └── 撤销时间：—
│
└── 订单状态 = 已撤销
    ├── 操作说明：已撤销
    ├── 核销时间：有
    └── 撤销时间：有
```
